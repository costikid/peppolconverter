## What is Peppol?

Peppol (Pan-European Public Procurement On-Line) is a set of open standards that allows businesses to exchange electronic documents — primarily invoices — across borders and between different software systems.

Think of it as a universal language for invoices. Instead of emailing a PDF and hoping the recipient's accounting software can read it, Peppol ensures the invoice arrives as structured data that can be processed automatically.

## Why Does It Matter?

For businesses dealing with public sector clients in Europe, Peppol compliance is increasingly **mandatory**. Several EU member states require suppliers to send e-invoices via the Peppol network.

Even outside the public sector, Peppol reduces:

- **Manual data entry** — invoices arrive as structured XML, not PDFs
- **Payment delays** — automated processing means faster approval cycles
- **Errors** — structured data is validated against a strict schema before sending

## Peppol BIS Billing 3.0

The most common Peppol document format is **BIS Billing 3.0**, based on the UBL 2.1 XML standard. It defines exactly which fields are required, how VAT must be represented, and how line items should be structured.
